# 행동 키워드 시스템 (초안)

> 2026-11-05 기획자 지시로 만든 새 핵심 시스템 초안이에요. **계획 문서이고, 아직 프로토타입에 넣지 않았어요.**
> [확정]은 기획자가 정한 것, [기본값]은 Claude가 채운 제안이에요.

## 1. 한 줄 요약

키워드를 **내 행동 4가지(평타·특수공격·패링·대시)에 붙여서**, 같은 키워드라도 붙인 행동마다 다른 효과를 내요. 키워드 두 개는 **물리 현상처럼 섞여서** 새 키워드가 돼요. 예를 들어 물과 바람이 섞이면 안개가 돼요.

## 2. 다른 시스템과의 관계

- [확정] 단순한 증강 시스템은 **보류**해요. 빌드의 중심은 이 시스템이에요.
- [기본값] 예전 효과형 증강(불길·서리·우레 등)과 태그 시너지(8.1)는 키워드가 대신해요. 축복 카드(작은 수치)는 그대로 둬요.
- [확정 2026-11-05] 동작 각인(9.2)은 이 시스템으로 **대체**해요. 인장 대신 키워드를 새기고, 자리는 7개(1·2·3타·대시·패링·반격·심)에서 행동 4개로 줄여요. 이음·각인석·심 자리는 없어지고, 그 역할은 합성과 키워드 등급이 맡아요.
- 예전에 제거한 "계층보스 키워드"와는 다른 시스템이에요. 그때는 런 전체에 걸리는 강력한 효과 1개였고, 이번에는 행동마다 붙이는 부품이에요.

## 3. 기본 구조

### 3.1 행동 자리 [확정: 4행동 / 기본값: 칸 수]

| 행동 | 처음 칸 | 최대 칸 | 언제 발동 |
| --- | --- | --- | --- |
| 평타 | 1 | 2 | 1·2·3타 모두 (3타는 효과가 더 큼) |
| 특수공격 (Q) | 1 | 2 | 회전베기 두 타 |
| 패링 | 1 | 2 | 패링 성공 순간과 그 뒤 반격 |
| 대시 | 1 | 2 | 대시와 대시 공격 |

- 둘째 칸은 중간보스(5·15·25층)를 잡을 때 행동 하나를 골라 열고, 상점에서도 열 수 있어요.
- 한 행동의 두 칸에 **섞일 수 있는 두 키워드**가 들어 있으면, 그 자리에서 **합성**할지 고를 수 있어요(4장).

### 3.2 키워드 얻기 [기본값]

| 어디서 | 무엇을 |
| --- | --- |
| 일반 층 | 키워드 카드 3장 중 1장. 새 키워드이거나, 가진 키워드의 등급 올리기예요. |
| 중간보스 | 둘째 칸 열기 + 키워드 1장 |
| 계층보스 | 합성 키워드 중 하나를 바로 얻거나, 2단계 합성 재료를 얻어요 |
| 상점 | 키워드 1장(파편), 칸 열기, 키워드 분리 |

- 같은 키워드를 다시 고르면 등급이 올라요. 등급은 1~3이고 수치가 커져요.
- 층과 층 사이에서는 키워드를 다른 행동으로 자유롭게 옮길 수 있어요. 전투 중에는 못 바꿔요.

## 4. 합성 규칙 [확정: 물리 법칙 기반 / 기본값: 표]

### 4.1 어떻게 합성하나

- 같은 행동의 두 칸에 섞일 수 있는 두 키워드가 있으면 합성할 수 있어요.
- **합성하면 두 키워드가 하나가 되어 한 칸만 차지해요.** 남은 칸에 키워드를 또 넣을 수 있어서 합성은 손해가 아니라 확장이에요.
- 합성 키워드 + 기본 키워드로 **2단계 합성**이 될 수 있어요(4.4). 2단계가 상한이에요.
- 합성은 되돌릴 수 없어요. 상점의 "분리"로만 둘로 나눠요.
- 합성 키워드의 등급은 재료 두 개 등급의 평균(올림)이에요.

### 4.2 기본 키워드 8종 — 무엇을 뜻하나

| 키워드 | 물리적 뜻 | 성격 |
| --- | --- | --- |
| 화염 | 열을 더함 | 지속 피해(화상), 팽창 |
| 냉기 | 열을 뺌 | 둔화 → 빙결 |
| 물 | 액체 | 젖음(다른 원소의 매개), 흐름 |
| 바람 | 기체의 흐름 | 밀어내기, 사거리 |
| 대지 | 고체와 질량 | 충격, 방어 |
| 전기 | 전하 | 연쇄, 마비 |
| 신속 | 속도와 시간 | 빨라짐, 쿨다운 |
| 복제 | 수(개수) | 한 번 더. 다른 키워드와 섞이지 않고 **같은 칸 짝을 복사**해요(4.3) |

### 4.3 기본 키워드 × 행동 효과표 [기본값]

| 키워드 | 평타 | 특수공격 (Q) | 패링 | 대시 |
| --- | --- | --- | --- | --- |
| **복제** | 한 박자 늦게 잔상이 같은 베기를 한 번 더 해요(50% 피해) | 회전베기가 한 바퀴 더 돌아요(둘째는 60% 피해) | 패링 뒤 반격이 2번까지 반격으로 쳐져요 | 대시를 시작한 자리에 1초 동안 분신이 남아 적의 주의를 끌어요 |
| **화염** | 맞은 적이 화상을 입어요(3초 지속 피해) | 회전 궤적에 2초 동안 불 고리가 남아요 | 성공 순간 공격자 앞에서 작은 폭발이 나요(열팽창) | 지나간 경로에 불길이 1.5초 남아요 |
| **냉기** | 3번 맞히면 1초 빙결해요 | 회전 뒤 서리 고리가 남아 둔화시켜요 | 성공하면 공격자가 즉시 1초 빙결해요 | 경로에 얼음판이 생겨 적이 미끄러져요 |
| **물** | 맞은 적이 젖어요(다른 원소 반응 준비, 이동 -10%) | 소용돌이가 주변 적을 안으로 끌어당겨요 | 성공 순간 주변 적이 젖고 체력을 조금 회복해요 | 대시 거리 +30%, 경로가 젖은 바닥이 돼요 |
| **바람** | 검풍으로 사거리가 +60px 늘어요 | 회오리가 적을 바깥으로 날려요 | 성공 순간 돌풍이 주변 적 투사체를 날려버려요 | 경로의 적을 옆으로 밀어내고, 대시 쿨다운이 -20%예요 |
| **대지** | 3타가 바닥을 쳐 충격파를 일으켜요 | 회전 중 바위 파편이 사방으로 튀어요 | 패링 판정이 2프레임 늘고, 실패해도 피해가 20% 줄어요 | 대시가 끝나는 자리에 착지 충격이 나요 |
| **전기** | 번개가 가까운 적 1명에게 튀어요 | 회전 중 몸에 전기장이 생겨 닿은 적이 감전돼요 | 성공하면 공격자에게 전류가 역류해 0.4초 마비돼요 | 대시가 짧은 순간이동이 되고, 경로의 적이 감전돼요 |
| **신속** | 평타 속도 +20% | 회전베기 재사용 시간 -40% | 퍼펙트 패링 구간이 1프레임 늘어요 | 대시를 연달아 2번 쓸 수 있어요 |

### 4.4 1단계 합성표 — 기본 키워드 둘 [기본값]

| 재료 | 결과 | 물리 현상 | 대표 효과 |
| --- | --- | --- | --- |
| 물 + 바람 | **안개** | 물방울이 공기에 흩어짐 | 행동 자리에 안개를 남겨요. 안개 속 적은 나를 놓치고 명중률이 떨어져요 |
| 물 + 화염 | **증기** | 기화와 팽창 | 증기 폭발(밀어내기 + 화상), 잠깐 시야를 가려요 |
| 물 + 냉기 | **얼음** | 응고 | 얼음 창이 적을 꿰뚫고 빙결시켜요 |
| 물 + 전기 | **전도** | 물이 전류를 옮김 | 젖은 적 전부에게 번개가 퍼져요 |
| 물 + 대지 | **진흙** | 흙과 물이 섞임 | 늪 장판이 생겨 크게 둔화시켜요 |
| 화염 + 바람 | **열풍** | 산소 공급과 연소 확산 | 불길이 바람 방향으로 번지고 커져요 |
| 화염 + 대지 | **용암** | 용융 | 오래 남는 용암 장판이 생겨요 |
| 화염 + 냉기 | **열충격** | 급격한 온도 차로 깨짐 | 화상과 빙결이 바뀌는 순간 큰 파쇄 피해를 줘요 |
| 화염 + 전기 | **플라스마** | 이온화된 기체 | 관통하는 고열 광선이 나가요 |
| 바람 + 대지 | **모래폭풍** | 침식 | 이동하는 모래 소용돌이가 계속 깎아요 |
| 바람 + 냉기 | **눈보라** | 찬 공기의 흐름 | 넓은 범위가 서서히 얼어붙어요 |
| 바람 + 전기 | **뇌운** | 공기 마찰과 방전 | 머리 위 구름이 일정 간격으로 낙뢰를 떨어뜨려요 |
| 대지 + 전기 | **자력** | 자기장 | 적과 적 투사체를 한곳으로 끌어모아요 |
| 대지 + 냉기 | **동토** | 얼어붙은 땅 | 오래 남는 결빙 지대가 생겨요 |
| 냉기 + 전기 | **초전도** | 냉각하면 저항이 0이 됨 | 빙결·둔화된 적 사이에서 번개가 끝없이 튀어요(같은 적은 한 번) |
| 신속 + 바람 | **음속** | 소리보다 빠름 | 행동 끝에 충격파(소닉붐)가 터져요 |
| 신속 + 대지 | **운동량** | 질량 × 속도 | 대시·돌진 피해가 이동 거리에 비례해 커져요 |
| 신속 + 화염 | **마찰열** | 빠른 마찰이 열을 냄 | 빠르게 연속 타격할수록 화상이 크게 쌓여요 |
| 신속 + 전기 | **섬광** | 빛의 속도 | 순간이동 거리 +50%, 도착 지점에 번개가 내리꽂혀요 |
| 신속 + 물·냉기 | 합성 없음 | — | 그냥 두 키워드가 따로 작동해요 |
| 복제 + 아무것 | 합성 없음 | — | 복제가 짝 키워드의 효과를 한 번 더 내요(예: 복제 + 화염 평타 = 화상 2중첩) |

- 합성 키워드도 어느 행동에 붙였느냐에 따라 모양이 달라요. 예: **안개**를 평타에 붙이면 베는 곳마다 작은 안개가 생기고, 대시에 붙이면 대시 경로가 안개 길이 되고, 패링에 붙이면 성공 순간 주변이 안개로 덮이고, 특수공격에 붙이면 회전하며 넓은 안개를 펼쳐요.
- 21쌍 전체의 행동별 효과(합성 19종 × 4행동)는 기획자가 방향을 정하면 다음 단계에서 채울게요.

### 4.5 2단계 합성 예시 [기본값]

| 재료 | 결과 | 물리 현상 |
| --- | --- | --- |
| 안개 + 전기 | **폭풍우** | 구름 속 방전 |
| 안개 + 냉기 | **서리안개** | 안개가 얼어붙음 |
| 증기 + 냉기 | **비** | 응결 — 넓은 범위가 젖음 |
| 용암 + 물 | **흑요석** | 급랭 — 날카로운 유리 파편 |
| 얼음 + 바람 | **우박** | 얼음 덩어리가 떨어짐 |
| 열풍 + 대지 | **화산** | 분화 |
| 뇌운 + 물 | **폭풍우** | 같은 결과를 다른 길로 만들 수 있어요 |

- 2단계 키워드는 계층보스 보상이나 2단계 재료로만 나와요. 런 하나에서 1~2개 만들 수 있는 정도를 목표로 해요.

## 5. 적 상태 반응 [기본값, 같은 표를 씀]

- 키워드가 적에게 남기는 상태(젖음·화상·냉각·대전·흙먼지)끼리도 **4.4 합성표와 같은 규칙으로 반응**해요.
- 예: 물 평타로 적을 젖게 만든 뒤 전기 대시로 지나가면, 그 순간 **전도** 반응이 터져요. 화상 중인 적을 냉기로 얼리면 **열충격** 파쇄가 나요.
- 그래서 행동 하나에 합성 키워드를 만들지 않아도, **행동끼리 순서**로 반응을 만들 수 있어요(평타 → 대시, 패링 → 반격). 빌드 설계와 손 조작이 같은 규칙으로 이어져요.
- 반응은 같은 적에게 0.5초에 한 번만 터져요.

## 6. 버그와 폭주를 막는 규칙 [기본값, 강력 추천]

- **세대 규칙:** 키워드가 만든 피해(잔상, 번개 튐, 폭발)는 다른 키워드를 다시 발동시키지 못해요. 복제의 잔상은 화염 같은 짝 효과만 싣고, 다시 복제되지 않아요.
- **반응 쿨다운:** 같은 적의 같은 반응은 0.5초에 한 번.
- **장판 상한:** 바닥에 남는 장판(불길, 용암, 얼음판, 늪)은 종류마다 동시에 6개까지.
- **피해 상한:** 한 번의 행동이 만든 키워드 추가 피해 합은 그 행동 피해의 300%까지.
- **보스 예외:** 빙결·마비는 보스에게 0.3초짜리 경직으로 바뀌어요.

## 7. 플레이 예시

1. **안개 회피 빌드:** 대시에 물 + 바람 → 안개 합성. 대시할 때마다 안개 길이 생겨 적이 나를 놓쳐요. 남은 칸에 신속을 넣어 대시 2연속.
2. **감전 사냥:** 평타에 물(젖음), 대시에 전기. 평타로 적을 적신 뒤 대시로 지나가면 전도 반응으로 무리 전체가 감전돼요.
3. **패링 열충격:** 패링에 냉기(성공 시 빙결), 평타에 화염. 패링으로 얼린 적을 화염 평타로 치면 열충격 파쇄가 터져요.
4. **복제 3타:** 평타에 복제 + 대지. 3타 충격파가 두 번 터져요.

## 9. 프로토타입 반영 (v0.8, 2026-11-05)

기획자 빌드 지시로 웹 프로토타입에 넣었어요. 설계와 다르거나 Claude가 정한 부분이에요.

- **넣은 것:** 기본 8종 × 행동 4개, 합성 19종, 적 상태 반응(젖음·화상·냉각·감전 사이 6종), 장판, 행동당 1~2칸, 가방 3칸, 키워드 판(옮기기·합성), 상점 분리.
- **합성 키워드의 행동별 모양 [기본값]:** 현상 하나를 정해 두고, 나는 자리와 크기만 행동마다 달라요.
  - 평타: 휘두를 때 첫 적중한 적 자리에서 한 번(3타는 더 크게)
  - 특수공격: 첫 타에 내 주변에서 크게
  - 패링: 패링한 적 자리에서 크게
  - 대시: 끝난 자리, 장판형은 지나간 경로 위 두 곳
  - 합성 키워드로 대시 공격·회전베기를 맞히면 재료 원소의 상태도 남아서 반응을 이어 갈 수 있어요.
- **보상 [기본값]:**
  - 일반 층: 키워드 3택1(가진 것이면 등급 +1) → 붙일 행동 고르기, 건너뛰면 파편 15
  - 정예 층: 위 + 축복 3택1
  - 중간보스: 둘째 칸 열기 + 키워드
  - 계층보스: 합성 키워드 3택1 + 칸 열기
- **상점 [기본값]:** 기본 키워드 3장(60, 가진 것 50) + 합성 1장(160), 칸 열기 120, 합성 분리 40, 가방 키워드 팔기 25.
- **첫 합성 연출:** 아이디어 E1을 넣었어요. 처음 터진 합성은 화면 가운데에 이름과 재료식이 뜨고 짧은 슬로모가 걸려요.
- **수치 차이:** 대지 패링은 받는 피해 -15%(설계 -20%)예요. 용암 장판 틱은 0.5초마다 4 × 등급이에요.
- **아직 없음:** 2단계 합성(4.5), 6장의 피해 상한 규칙, 상극 약화.
- **보류:** 증강과 동작 각인(인장)은 보상에 나오지 않아요. 코드는 남아 있어요.
