## 1. 한 줄 요약

탑 쿼터뷰 하데스식 3D 핵앤슬래시 로그라이트. 플레이어블 캐릭터는 여러 마녀이고, 프로토타입은 마녀 한 명으로 만들어요. 30층을 내려가며 한 층에 한 번 싸우고, 층마다 보상으로 빌드를 쌓아 31층 최종 보스를 잡아요. 엔진은 Unity이고, 웹 프로토타입은 손맛·규칙 검증용이에요(코드는 이식하지 않음).

- **조작의 핵심:** 회피(대시)와 방어. 회피는 안전한 답, 방어는 위험하지만 보상이 큰 답.
- **빌드의 핵심:** 계약과 태그 시너지. 같은 태그 계약을 모으면 그 태그 효과가 켜져요.

```
[계층 지도에서 칸 고르기] → [전투 1번: 적 섬멸] → [보상: 축복 / 계약 / 파편]   
        ↑                                                     │
        └──────── 10층마다 계층보스, 30층 뒤 31층 최종 보스 ←──┘
```

## 5. 조작 (전투 코어)

재정비의 중심이 될 부분이라 수치까지 적었어요. 수치는 프로토타입 값이에요.

### 5.1 평타 — 하데스식 [확정]

| 항목 | 값 |
| --- | --- |
| 콤보 | 3타. 피해 14 / 16 / 28 |
| 이동 | 휘두르는 동안 이동 입력 무시, 타마다 전진 스텝(1·2타 230, 3타 360). 방향은 조준 70% + 이동 30% |
| 선딜 / 후딜 | 1·2타 0.05 / 0.11초, 3타 0.10 / 0.24초 |
| 취소 | 대시·방어로 어느 단계든 즉시 취소. 타마다 재조준 |
| 평타 걸림 | 첫 적중 순간 0.07초 동안 내 동작만 0.25배, 후딜에서 갚아 전체 길이 그대로 |
| 넉백 | 1·2타 없음, 3타만 260(정예 60%). 슈퍼아머 적·보스는 안 밀림 |

### 5.2 대시(회피) [확정, 세부 기본값]

- 무적 회피, 쿨다운 0.55초.
- 자유 각도: 커서가 이동 방향 앞쪽 ±90° 안이면 커서 쪽, 아니면 이동 키 방향(도망 대시). [기본값]
- 끝날 때 걷기의 1.3배 속도로 넘겨 멈칫 없이 걷기로 이어짐. [기본값]

### 5.3 대시 공격 — 세피리아 게임필 참고 [확정]

- 대시 중 공격, 또는 대시·공격 0.1초 안 동시 입력 → 대시 방향 베기. 대시 직후 0.2초까지 가능.
- 대시 속도를 실은 채 미끄러지며 베고 0.3초에 걸쳐 멈춤. 추가 스텝 없음.
- 판정 = **지나간 경로**: 대시 시작점부터 칼끝 90px까지, 폭 100px 띠. 뚫고 지나간 적도 맞음. 피해 22.

### 5.4 마법 (회전베기, Q) [확정]

- 슈퍼아머: 일반 공격에는 피해만 받고 안 끊김. 금색·붉은색 공격에는 끊김.
- 자체 취소: 첫 타 뒤부터 대시·방어로, 둘째 타 뒤 후딜은 평타로도 끊김. 첫 타 전에는 못 끊음.
- 재사용 6초(1회 충전).

### 5.5 방어 [확정]

| 항목 | 값 |
| --- | --- |
| 버튼 | 전용(마우스 오른쪽 / K). 모든 캐릭터 공통 |
| 판정 | 0.2초(12프레임), 세키로 쳐내기 수준 |
| 퍼펙트 | 앞 4프레임(0.067초) → 다음 공격 1회 피해 +50%(2초 안), 반격과 곱 |
| 헛방어 | 경직 없음. 연타 벌칙만: 0.5초 안 누른 횟수만큼 판정 2프레임씩 감소, 최소 4프레임 |
| 성공 효과 | 받는 피해 0, 투사체 반사, 궁극기 게이지 +8%, 반격 창 0.6초 |
| 적 경직 | 일반·정예 흰 0.6초 / 금 1.2초(밀려남). 보스 흰 0.3초 / 금 0.8초 |
| 반격 | 방어 후 0.6초 안 첫 공격 = 치명 확정, 위력 +100%. 버튼 추가 없음 |
| 없는 것 | 체간 게이지·그로기·결정타(제거, 다시 안 씀) |

## 6. 성장 시스템

### 6.1 계약 — 빌드의 핵심 [확정 2026-11-19, 목록·수치 기본값] · 프로토 △

"계약"은 예전 이름 "증강"이에요(2026-11-19 확정, 6.5).

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 역할 | 효과를 만들고 규칙을 바꿈(속성 전환, 상태 이상, 복제·증식, 조건). 숫자만 올리지 않음 | 확정 |
| 두 종류 | **행위 계약** = 행동 하나(평타·마법·방어·대시·궁극기)에 붙여 그 행동 강화 / **존재 계약** = 패시브처럼 전체에 관여 | 확정 2026-11-19 |
| 행위 계약 | 행동 5개(궁극기 포함). 대부분 붙는 행동이 정해져 있음. 개수 제한·칸 없음. 옮기기 불가, 상점 파기만 | 확정 2026-11-19 |
| 단계 | 같은 계약을 다시 맺으면 단계 +1(최대 3) | 기본값 |
| 존재 계약 | 개수 제한 없음, 늘 켜짐, 상점 파기만 | 확정 |

| 보상 화면 | 완전 무작위(종류 비율 없음). 취소하면 리롤권 1(프리즘 화면 2) | 확정 2026-11-19 |
| 얻는 곳 | 중간보스(5·15·25층) 3택1. 계층보스(10·20·30층)는 계약 3택1 + **프리즘 계약 3택1** | 확정 |
| 등급 | 실버·골드·프리즘. 한 화면 3장은 같은 등급, 카드별 무료 리롤 1회 | 확정 |
| 런당 개수 | 9개 정도(프리즘 보장 3개) | 확정 구조 |
| 건너뛰기 | 계약 = 리롤권 1, 프리즘 계약 = 리롤권 2 | 확정 |
| 효과형 계약 | 불길·서리·우레·꿰뚫기·갈래·메아리·끊어내기·낙인·덧충전 (같은 것 재선택 시 최대 3단계) | 기본값 |
| 규칙 계약 | 방어 계열(칼날 받이·흔들기·연속 응수·되갚음·붉은 쇠·빈틈 사냥), 그 밖(피의 갈증·질풍 발·철갑·단골 손님·별의 문장 등) | 기본값 |
| 안전 규칙 | 세대 표시(효과가 효과를 무한히 부르지 않음), 발동 순서 고정, 투사체·번개·장판 상한, 한 타격에 속성 하나, 보스는 강한 제어 → 피해 | 기본값 |
| 보기 | 고른 계약과 시너지 상태는 언제든(전투 중 포함) 볼 수 있어야 함 | 확정 |

### 6.2 태그 시너지 [방식 확정, 태그·수치 기본값] · 프로토 ❌

- 시너지는 특정 계약 둘의 짝이 아니라 **태그 수**로 켜져요. 계약마다 태그 1~2개, 같은 태그를 2·3·4개 모으면 단계별 효과가 켜지고 누적돼요.
- 같은 계약을 다시 골라도 태그 수는 1개로 셈해요. 아이템은 세지 않아요.
- 태그 8종(기본값): 원소·검기·응수·붕괴·처형·질풍·철벽·천운.
- 프로토타입은 아직 예전 **짝 시너지 10종** 그대로예요.

### 6.3 축복 카드 [확정: 일반 층 보상, 수치 기본값] · 프로토 ✅

3장 중 1장, 같은 축복은 계속 쌓여요. 예리함(피해 +4%), 튼튼함(체력 +6), 손놀림(공속 +3%), 발놀림(이속 +3%), 호흡(대시 쿨 -4%), 잔불(궁극기 충전 +5%), 집중(방어 판정 +0.01초, 최대 +0.05초).

### 6.4 속성과 아이템

- 속성: 물리·화염·냉기·번개 4종 [확정 방향]. 효과형 계약이 속성을 바꿔요. 약점 +25% / 내성 -25%는 기본값.
- 아이템: 상점에서 파편으로 완성품을 사요 [확정]. 동작 각인(인장)은 쓰지 않으니 **장착 방식은 다시 정해야 해요** [미정].

### 6.5 용어 [확정 2026-11-19]

- **계약** = 예전 "증강". 마녀가 어두운 존재와 맺는 거래라는 느낌이에요. 후보였던 비약·주문·마도서 장 중에서 기획자가 골랐어요.
- 등급(실버·골드·프리즘)과 "태그 시너지"라는 말은 그대로예요.
- **마법** = 예전 "특수공격"(프로토타입의 회전베기 Q는 임시 예시).
- **방어** = 예전 "패링".
- 예전에 버린 "난이도 계약"과는 다른 것이에요.
