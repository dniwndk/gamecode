# 마녀 계약 전투 프로토타입 (웹)

설계서(`game-design.md`, 2026-11-19 마녀 컨셉 기준)와 계약 시트(`contract-seed.json`: 계약 77개·태그 11개)를 바탕으로 만든 플레이 가능 프로토타입이에요. v0.9(2026-11-21)부터 행동 키워드를 없애고 **계약과 태그 시너지**가 빌드의 중심이에요. 2026-11-05부터 **쿼터뷰(위에서 비스듬히 내려다보는) 2.5D 그레이박스**로 그려요. 전투 로직은 2D 평면 그대로이고, 그릴 때만 3D로 올려요. 그림은 회색 상자·캡슐 수준이고, 수치는 설계서의 기본값과 첫 기준값이에요.

## 실행

`index.html`을 브라우저로 열면 돼요(WebGL 필요). 빌드는 `node build.mjs` (src/ + vendor/three.min.js → index.html, artifact.html).

### 그리는 방식 (src/render3d.js)

- three.js r158. 카메라는 바닥에서 50° 내려다보는 원근 카메라, 플레이어가 보는 쪽으로 살짝 앞서가고 보스가 있으면 보스 쪽으로 30% 끌려요. 흔들림·줌은 카메라를 움직여요.
- 게임 좌표 (x, y) → 3D (x, 높이, y). 아레나는 바닥판 + 벽 4면 + 기둥(원기둥), 실제 그림자(방향광).
- 바닥에 붙는 것(공격 예고, 판정 범위, 등장 표식, 웅덩이, 균열·그을음·처치 자국)은 아레나 크기 캔버스에 2D로 그린 뒤 바닥 텍스처로 깔아요. 그래서 예고선이 바닥에 정확히 투영돼요.
- 공중 연출(파티클, 파편, 베기 궤적, 피해 숫자, 머리 위 체력 바, 섬광 느낌표)은 3D 좌표를 화면으로 투영해 위에 겹친 2D 캔버스에 그려요. HUD·메뉴·계약 창은 그대로예요.
- 적 도형: 돌격병 캡슐, 원혼불 팔면체(떠 있음), 강타수 상자, 방패병 캡슐+방패판, 자폭병 구+도화선, 치유사 원뿔, 보물 상인 십이면체, 보스 큰 캡슐+고리. 정예는 금색, 보스는 흰색 바닥 고리.

## 들어간 것

- 런: 30층(계층 3개) + 31층 최종 보스, 계층마다 10줄 경로 지도(전투·저주 전투·상점·회복·이벤트·보스)
- 전투: 3타 콤보(넉백은 3타에만 약간, 슈퍼아머·보스 제외; 맞는 순간 0.07초 칼이 몸에 걸리는 느낌, 후딜에서 시간을 갚아 전체 길이는 그대로; 하데스식: 휘두르는 동안 이동 대신 전진 스텝, 짧은 선·후딜, 대시·방어으로 언제든 취소, 타마다 재조준), 마법(Q, 임시 회전베기: 일반 공격엔 슈퍼아머, 금색·붉은 공격엔 끊김, 첫 타 뒤 대시·방어 취소, 둘째 타 뒤 평타 취소), 대시(무적, 커서가 이동 방향 앞쪽 ±90° 안이면 커서 쪽 자유 각도, 아니면 이동 키 방향, 끝나면 멈칫 없이 걷기로 이어짐), 대시 공격(세피리아식: 대시 중 공격하면 대시 속도를 싣고 미끄러지며 베다가 0.3초에 걸쳐 멈춤, 대시·공격 0.1초 안 동시 입력도 대시 찌르기, 대시 후 0.2초까지, 추가 전진 없음, 판정 = 대시 시작점부터 칼끝 90px까지 지나간 경로 띠 폭 100px), 방어(세키로 수준: 판정 0.2초=12프레임, 앞 4프레임은 퍼펙트 방어 → 다음 공격 +50%, 헛방어 경직 없음, 연타 벌칙으로 판정이 2프레임씩 줄어 최소 4프레임·0.5초 뒤 회복, 0.2초 선입력·히트스톱 중 입력 보관·평타/대시 중 즉시 취소, 누르는 순간 소리·고리), 반격(0.6초, 치명 확정 +100%), 섬광 3색(금색 = 강공격, 방어하면 긴 경직), 체간·그로기 없음(2026-11-05 제거, 방어은 경직만), 투사체 반사, 벽꿍, 적끼리 충돌, 히트스톱·흔들림·슬로모
- 적 6종 + 보물 상인, 적 조합 16개, 층 변형자 5종, 등장 방식(일제·파상·매복), 기름·물웅덩이 지형 반응
- 보스: 중간보스·계층보스·최종 보스 (임시 공통 패턴, 설정은 기획자가 나중에 제공)
- **계약과 태그 시너지 (v0.9, src/contracts.js)**
  - 계약 75개: 시트 77개 중 아이템·각인 방식에 기대는 수집가·확장 가방 2개만 뺐어요. 행위 계약(평타·마법·방어·대시·궁극기 중 한 행동을 강화) + 존재 계약(늘 켜짐). 등급 실버·골드·프리즘.
  - 불길·서리·우레·덧충전은 맺을 때 붙일 행동을 골라요. 행동마다 효과 줄이 달라요(예: 불길 평타 = 화상, 대시 = 지나간 길에 불길). 다른 행동에 또 맺으면 따로 작동하고 태그는 1개로 세요.
  - 불길·서리·우레·꿰뚫기·갈래·메아리·끊어내기·낙인은 다시 맺으면 단계가 올라요(최대 3). 나머지는 1단계.
  - 태그 11종(원소·검기·응수·붕괴·처형·질풍·철벽·천운·권속·대가·의식), 같은 태그 2·3·4개에서 효과가 켜지고 누적돼요.
  - 보상(설계서 6.1): 일반·정예·저주 층 = 축복 3택1, 중간보스(5층) = 계약 3택1, 계층보스(10층) = 계약 3택1 + 프리즘 계약 3택1. 취소하면 리롤권 1(프리즘 2). 한 런에 계약 9개쯤.
  - **계약 시험 런**(처음 화면): 모든 전투 층에서 계약도 골라요. 계약·태그를 빨리 모아 보는 용도예요.
  - 계약 카드에 태그가 몇 개째가 되는지("원소 1 → 2")와 새로 켜지는 효과가 보여요. 계약 창(Tab)에 행동별 계약, 태그 11종의 단계, 능력치. 전투 화면 왼쪽에 태그 수, 아래에 행동별 계약.
  - 상점: 축복 3장·회복 물약을 팔고, 계약 파기(30 파편)를 해요. 맺은 계약은 옮길 수 없어요. 아이템은 방식이 정해지지 않아 없어요.
  - 새로 넣은 전투 요소: 보호막, 소환물(벌·까마귀·유도 부적·환영), 개구리 변이, 저주 표식, 궁극기 효과 시간(임시: 쓴 뒤 4초 동안 1초마다 주변 파동), 몸집 변화, 의식 과제.
  - "위력 N%"에 기준이 없는 계약은 기준 위력 30, "평타 위력"은 16으로 계산했어요(contracts.js의 POW, ATK_POW). 수치는 시트 그대로라 약한 것이 섞여 있어요.
  - 디버그 패널(`): 등급별 계약 고르기, 계약 목록에서 바로 맺기.
- 축복 7종(정예 층·회복 칸), 리롤(카드별 무료 1회 + 리롤권), 건너뛰기 보상, 회복, 임시 이벤트 3종, 결과 화면(맺은 계약·태그)
- 도트 효과(pixelfx 시트, src/spritefx.js + fx/): 타격 스파크(맞는 방향으로 회전), 치명·무거운 타격엔 충격 스파크 추가, 방어(금색은 더 크게), 번개 튐에 번개 호, 감전 중엔 전기 스파크가 적을 따라다님. 시트는 빌드 때 base64로 묶여 `SHEETS` 상수가 되고, 카메라를 바라보는 판에 프레임 UV를 바꿔 재생(가산 혼합, 가장 가까운 픽셀 필터). 새 효과는 pixelfx로 `--sheet` 렌더한 png+json을 fx/에 넣고 `SpriteFX.DEF`에 크기만 적으면 돼요.
- 3D 손맛: 대시 잔상(반투명 캡슐), 찌그러짐(스케일), 피격 떨림, 공격 전 부풀기, 칼 휘두름(1~3타·회전·방어 자세), 반격 창 바닥 고리
- 손맛 연출: 공격 방향으로 밀리는 흔들림, 히트스톱은 평타 3타와 처치 공격에만(방어·피격은 유지), 반격·퍼펙트·금색 방어의 반전 임팩트 프레임, 색수차, 베기 궤적, 대시 잔상과 먼지, 캐릭터·적 찌그러짐, 처치 시 파편과 바닥에 남는 자국(내려찍기 균열, 폭발 그을음), 연속 타격 계수기, 3연속 처치 슬로모, 시선 방향 카메라, 저체력 붉은 맥동, 타별 음높이가 다른 타격음

## 자동 검증

`tests/`에 Playwright 스크립트가 있어요(`window.__norender = true`로 그리기를 건너뛰어 빠르게 돌려요).

- `node tests/each.cjs`: 계약을 하나씩, 그리고 전부 맺고 봇으로 싸워 오류를 봐요.
- `node tests/full.cjs <seed> <시험 런 0|1> <무적 0|1>`: 31층 완주.
- `node tests/spot.cjs`: 변성·판도라·차용증·과제·보호막·두 번째 숨 확인.

v0.9 결과: 계약별 전투 오류 0건, 무적 완주 3회(보통 런 1, 시험 런 2) 오류 0건. 무적을 끈 봇은 7~8층에서 쓰러져요(v0.8 이전과 비슷).
