# 전투 빌드 프로토타입 (웹)

설계서(`game-design.md`, 2026-11-05 기준)를 바탕으로 만든 첫 플레이 가능 프로토타입이에요. 2026-11-05부터 **쿼터뷰(위에서 비스듬히 내려다보는) 2.5D 그레이박스**로 그려요. 전투 로직은 2D 평면 그대로이고, 그릴 때만 3D로 올려요. 그림은 회색 상자·캡슐 수준이고, 수치는 설계서의 기본값과 첫 기준값이에요.

## 실행

`index.html`을 브라우저로 열면 돼요(WebGL 필요). 빌드는 `node build.mjs` (src/ + vendor/three.min.js → index.html, artifact.html).

### 그리는 방식 (src/render3d.js)

- three.js r158. 카메라는 바닥에서 50° 내려다보는 원근 카메라, 플레이어가 보는 쪽으로 살짝 앞서가고 보스가 있으면 보스 쪽으로 30% 끌려요. 흔들림·줌은 카메라를 움직여요.
- 게임 좌표 (x, y) → 3D (x, 높이, y). 아레나는 바닥판 + 벽 4면 + 기둥(원기둥), 실제 그림자(방향광).
- 바닥에 붙는 것(공격 예고, 판정 범위, 등장 표식, 웅덩이, 균열·그을음·처치 자국)은 아레나 크기 캔버스에 2D로 그린 뒤 바닥 텍스처로 깔아요. 그래서 예고선이 바닥에 정확히 투영돼요.
- 공중 연출(파티클, 파편, 베기 궤적, 피해 숫자, 머리 위 체력 바, 섬광 느낌표)은 3D 좌표를 화면으로 투영해 위에 겹친 2D 캔버스에 그려요. HUD·메뉴·증강 창은 그대로예요.
- 적 도형: 돌격병 캡슐, 원혼불 팔면체(떠 있음), 강타수 상자, 방패병 캡슐+방패판, 자폭병 구+도화선, 치유사 원뿔, 보물 상인 십이면체, 보스 큰 캡슐+고리. 정예는 금색, 보스는 흰색 바닥 고리.

## 들어간 것

- 런: 30층(계층 3개) + 31층 최종 보스, 계층마다 10줄 경로 지도(전투·저주 전투·상점·회복·이벤트·보스)
- 전투: 3타 콤보, 대시(무적), 대시 찌르기, 패링(0.18초, 헛패링 경직, 연타 시 판정 절반), 반격(0.6초, 치명 확정 +100%), 섬광 3색, 정예·보스 체간과 그로기·결정타, 투사체 반사, 벽꿍, 적끼리 충돌, 히트스톱·흔들림·슬로모
- 적 6종 + 보물 상인, 적 조합 16개, 층 변형자 5종, 등장 방식(일제·파상·매복), 기름·물웅덩이 지형 반응
- 보스: 중간보스·계층보스·최종 보스 (임시 공통 패턴, 설정은 기획자가 나중에 제공)
- 보상: 축복 7종, 증강 25종(효과형 9종 포함, 키워드 없음), 계층보스는 증강 + 프리즘 증강, 리롤(카드별 무료 1회 + 리롤권), 건너뛰기 보상
- 동작 각인: 자리 7개(1~3타·대시·패링·반격·심), 인장 18종, 이음(같은 계열 +20%), 사슬 마무리, 각인석, 보조 가방
- 상점(인장, 각인석, 자리 열기, 새로고침), 회복, 임시 이벤트 3종, 결과 화면
- 도트 효과(pixelfx 시트, src/spritefx.js + fx/): 타격 스파크(맞는 방향으로 회전), 치명·무거운 타격엔 충격 스파크 추가, 패링(금색은 더 크게), 번개 튐에 번개 호, 감전 중엔 전기 스파크가 적을 따라다님. 시트는 빌드 때 base64로 묶여 `SHEETS` 상수가 되고, 카메라를 바라보는 판에 프레임 UV를 바꿔 재생(가산 혼합, 가장 가까운 픽셀 필터). 새 효과는 pixelfx로 `--sheet` 렌더한 png+json을 fx/에 넣고 `SpriteFX.DEF`에 크기만 적으면 돼요.
- 3D 손맛: 대시 잔상(반투명 캡슐), 찌그러짐(스케일), 피격 떨림, 공격 전 부풀기, 칼 휘두름(1~3타·회전·패링 자세), 반격 창 바닥 고리, 그로기 기울어짐
- 손맛 연출: 공격 방향으로 밀리는 흔들림, 타별 히트스톱(3타·반격이 더 무겁게), 반격·결정타·금색 패링의 반전 임팩트 프레임, 색수차, 베기 궤적, 대시 잔상과 먼지, 캐릭터·적 찌그러짐, 처치 시 파편과 바닥에 남는 자국(내려찍기 균열, 폭발 그을음), 연속 타격 계수기, 3연속 처치 슬로모, 시선 방향 카메라, 저체력 붉은 맥동, 타별 음높이가 다른 타격음
- 증강 시너지 10종, 증강 창(Tab: 보유 증강·효과·시너지·축복 포함 능력치, 전투 중 열면 일시정지), 전투 화면에 보유 증강 상시 표시

## 아직 없는 것

캐릭터별 패시브·액티브·궁극기(공통 임시 기술만), 보스 고유 설정, 증강 세트, 선택형 도전, 메타 진행, 게임패드, 진짜 그림·소리.

## 자동 검증

`window.__proto.auto(true)`로 간단한 봇이 싸우고, 무적 모드에서 31층 완주까지 오류 없이 도는 것을 확인했어요(3D 전환 후에도 동일). 소프트웨어 렌더링 환경에서는 `G3.renderer.setSize(320, 180, false)`로 줄여서 돌렸어요.
