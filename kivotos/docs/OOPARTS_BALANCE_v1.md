# 오파츠 밸런스 측정 v1 (2026-10-30)

지금 빌드(미리보기 런·흉내 전투)에서 자동 플레이 봇으로 잰 오파츠 55종의 힘이다. 해석과 조정안은 공유 문서 「오파츠 밸런스 측정 v1」(https://claude.ai/artifact/4R3G9JkkrKmtb6fZALwC1h)에 있고, 이 파일은 원자료와 다시 재는 법을 남긴다. 조정안 12종은 D-020으로 [OOPARTS_v1.md](OOPARTS_v1.md)에 반영했고, 조정 후 값은 맨 아래에 있다.

## 방법

- 봇: `scripts/balance/bot.ts`. 합성 우선 영입, 편성이 모자라면 비싼 학생, 전투 수에 맞춘 레벨업, 2장부터 여유 골드로 새로고침. 전략·장비는 첫 번째 제안.
- 단독(`single`): 오파츠 하나를 1전부터 가진 채 400판. 같은 시드 400개의 오파츠 없는 판과 짝지어 승수(15전 중 이긴 전투) 차이를 본다. 도중 제안은 건너뛴다(구조 요청은 받는다).
- 시너지 집중(`focus`): 특정 시너지 학생에게만 걸리는 13종은 그 시너지 학생을 우선 사고 출전시키는 봇으로 400판, 같은 봇의 오파츠 없는 판과 비교.
- 흐름(`flow`): 실제 획득 경로에서 늘 건너뛰기 / 첫 번째 / 무작위 1,000판씩.
- 오차: 짝 비교 표준오차 ±0.08~0.2승. ±0.1승 안은 효과 없음으로 본다(대기 14종이 모두 −0.05).

다시 재기(판당 약 0.05초, 단독 56조건 × 400판은 프로세스 4개로 약 10분):

```
npx tsx scripts/balance/oopart-balance.ts single 400 0-13 > single_0.json   # 조건 0~55를 나눠 병렬로
npx tsx scripts/balance/oopart-balance.ts focus 400 > focus.json
npx tsx scripts/balance/oopart-balance.ts flow 1000 > flow.json
```

## 한계

1. 흉내 전투다. 시너지 단계 효과가 전투에 없어서 시너지에 기대는 오파츠는 실제보다 약하게 나온다. 진짜 전투 엔진(M2·M3)이 들어오면 다시 잰다.
2. 봇은 전략을 고르지 않고, 대기석 경제를 쓰지 않고, 3성을 거의 못 만든다. 보이니치 사본·하니와·팔각형 헤일로 파편·모모프렌즈 박스는 제대로 재지 못했다.
3. 단독 측정은 1전부터 보유. 희귀·전설은 실제로 1장 보스 뒤에 오므로 체감은 표보다 작다.
