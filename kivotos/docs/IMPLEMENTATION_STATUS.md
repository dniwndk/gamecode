## 학생·시너지 정적 감사 (2026-10-30)

전투 엔진이 없어 효과가 "실행되는지"는 볼 수 없다. 대신 데이터로 확인할 수 있는 것을 전수 검사했다.

- 참조: 효과·시너지·전략·장비 문장의 `u_`·`syn_`·`eff_`·`en_`·`st_` ID 전부 실재. 효과 주인 표기와 실제 묶인 곳 일치(454/454).
- **고친 것(D-014)**: 동아리·역할군 상위 단계 33개가 「[하위 효과 포함]」 참조만 있어, v2.1 6장 "최고 단계 하나만 등록" 규칙대로면 하위 효과가 사라지던 문제. 본문을 풀어 씀. 발키리 3단계에 수배자 명시.
- **고친 것(D-015)**: 띄어쓰기가 빠진 효과 8개, 폐기된 시너지 이름이 남은 전략·장비 문구 4곳.
- **확인만 한 것(의도된 설계)**: 호시노와 무장 호시노 동시 편성(v2.1 T38에서 허용), 아비도스 5단계가 둘을 모두 셈.
- **사용자 판단이 필요한 것**: 2장 "1코는 제어·SP·팀 효과 없음" 기준과 다른 1코 학생 5명 — 스즈미(스킬·필살기 기절), 후부키(필살기 지연), 코코나(필살기 전방 전원 치유), 코타마·노도카(후방 정기 지원이 전방 전원 버프).
- **효과가 헛도는 조합(설계 메모)**: 후방 학생은 HP 피해를 받지 않으므로, 수행부(미모리)·선도부 4단계 피해 감소(아코·치나츠)·디저트부 4단계 "모두 살아 있음"(아이리)은 후방 구성원에게 의미가 없거나 항상 참이다.
