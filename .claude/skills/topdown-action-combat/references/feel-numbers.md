# 손맛 수치표 (60fps 프레임 기준, 프로토타입 기본값)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 일반 타 1·2 | 선딜 4 / 판정 3 / 후딜 12, 데미지 10, 사거리 1.3u, 호 140° | 넉백 6u/s, 히트스톱 3f, 셰이크 1.5px·5f, 전진 0.25u |
| 마무리 타 | 선딜 7 / 판정 4 / 후딜 22, 데미지 25, 사거리 1.6u, 호 200° | 넉백 15u/s, 히트스톱 8f, 셰이크 4px·10f, 전진 0.5u |
| 대시 공격 | 선딜 3 / 판정 3 / 후딜 14, 데미지 15 | 히트스톱 5f |
| 처치 타 | 히트스톱 ×1.6, 넉백 ×1.5, 셰이크 ×1.6 | 사망 연출은 히트스톱이 끝난 뒤 |
| 플레이어 피격 | 히트스톱 6f, 넉백 9u/s, 셰이크 3px·10f, 무적 0.6s | 공격 중이면 끊김 |

| 대시 | 19u/s × 10f, 무적 8f, 쿨다운 0.2s | 대시 3f 이후 공격 입력 → 대시 공격 |
| 입력 버퍼 | 0.15s | 0이면 정확한 프레임 입력 필요 |
| 콤보 리셋 | 0.4s | |
| 에임 보정 | ±35°, 사거리 +1.2u | 점수 = 각도 + 거리×10 |
| 적 | 체력 60, 속도 2.4u/s, 예고 34f(4f 간격 깜빡임), 돌진 9u/s × 10f, 휴식 40f, 경직 18f | |
| 넉백 감쇠 | v *= exp(-14·dt) | 이동 거리 ≈ v/14 |
| 카메라 | 320×180 (16 PPU, ortho 5.625), 추적 lerp 8, 조준 방향 선행 0.6u | 셰이크는 첫 프레임 타격 방향, 이후 ±교차, k² 감쇠, 픽셀 스냅 |

## 구현 원칙
1. 히트스톱은 `Time.timeScale` 대신 **공격자와 피격자만** 멈춘다. 다른 적은 계속 움직이고, 입력은 멈춘 동안에도 버퍼에 쌓인다.
2. 넉백은 히트스톱이 **끝난 뒤** 적용한다. (멈춤 → 밀림 순서가 무게감을 만든다)
3. 피격자는 히트스톱 동안 1px 좌우 진동, 플래시는 히트스톱 + 3f.
4. 대시 캔슬은 선딜과 후딜에서만 허용, 판정 프레임은 지킨다.
5. 다음 타 입력은 후딜에서만 받고, 버퍼로 미리 누른 입력을 이어 준다.
6. 모든 적 공격은 예고(깜빡임) → 공격 → 빈틈의 3박자.
