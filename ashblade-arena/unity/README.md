# Ashblade Arena: 유니티 버전

웹 버전([`../web/ashblade-arena.html`](../web/ashblade-arena.html))과 같은 전투, 같은 연출을 유니티로 옮긴 것입니다. 이미지나 사운드 파일 없이 도트, 이펙트, 효과음을 모두 코드로 만들기 때문에 스크립트만 넣으면 바로 돌아갑니다.

## 설치

1. 유니티 2021.3 이상에서 2D 프로젝트를 엽니다. Built-in, URP, URP 2D 렌더러 모두 됩니다.
2. `Assets/Ashblade` 폴더를 프로젝트의 `Assets` 아래에 그대로 복사합니다. `Resources` 폴더 안의 셰이더 세 개도 꼭 같이 넣어 주세요.
3. 빈 씬을 만들고, 빈 GameObject에 `AshGame` 컴포넌트를 붙인 뒤 Play를 누릅니다.

카메라, 320×180 렌더 타깃, 오디오 리스너는 `AshGame`이 알아서 만듭니다. 씬에 있던 Main Camera는 자동으로 꺼집니다. 새 Input System과 예전 Input Manager 둘 다 지원하며, 프로젝트 설정의 Active Input Handling을 따라갑니다.

## 실험 패널

F1로 여는 패널에서 히트스톱, 화면 흔들림, 넉백, 입력 버퍼 같은 기본 피드백과 임팩트 프레임, 킬캠 줌, 슬로모션, 스쿼시, 데미지 숫자, 잔상, 글로우, 바닥 흔적, 색수차, 진동을 하나씩 켜고 끌 수 있습니다. "Full juice", "V1 level"(1차 테스트 수준), "All off" 프리셋으로 바로 비교할 수 있고, 같은 값은 `AshTuning` 컴포넌트 인스펙터에서도 조절됩니다. 공격 프레임, 데미지, 넉백, 적 능력치도 인스펙터에서 바꿀 수 있습니다.

## 인챈트

평타(3타 콤보, 대시 찌르기)와 스킬(회전베기, 잿불 폭발)에 키워드 인챈트를 붙여 강화할 수 있습니다. 키워드마다 레벨 1~3이 있습니다.

| 키워드 | 효과 |
|---|---|
| 관통 PIERCE | 공격할 때 적을 꿰뚫는 검기가 날아갑니다. 회전베기와 폭발은 사방으로 뿜습니다. |
| 화염 FIRE | 화상이 쌓이고, 불탄 적은 죽을 때 폭발해 주변에 불을 옮깁니다. |
| 냉기 FROST | 맞을수록 느려지다가 4중첩이면 얼어붙습니다. 언 적을 치면 파쇄 피해가 들어갑니다. |
| 연쇄 CHAIN | 맞은 적에서 주변 적으로 번개가 튑니다. |
| 증식 SPLIT | 맞은 적에서 다른 적을 쫓는 파편이 갈라져 나갑니다. |
| 복제 ECHO | 잠시 뒤 그림자 분신이 같은 공격을 한 번 더 합니다. |

키워드끼리 섞입니다. 관통 검기, 증식 파편, 연쇄 번개에도 화염과 냉기가 실리고, 분신은 관통까지 함께 씁니다. 인챈트가 만든 효과에서는 연쇄와 증식이 다시 터지지 않으므로 끝없이 불어나지 않습니다.

### 시너지

같은 슬롯(평타 또는 스킬)에 두 키워드가 함께 있으면 시너지가 켜집니다. 6종 중 두 개씩, 15가지입니다.

| 조합 | 이름 | 효과 |
|---|---|---|
| 관통+화염 | FLAME TRAIL | 검기가 지나간 자리에 불길이 남아 적을 태움 |
| 관통+냉기 | FROST TRAIL | 검기가 지나간 자리에 얼음 장판이 남아 냉기를 쌓음 |
| 관통+연쇄 | STORM WAVE | 검기가 날아가며 주변 적에게 번개를 떨굼 |
| 관통+증식 | SHRAPNEL | 검기가 사거리 끝에서 유도 파편으로 터짐 |
| 관통+복제 | TWIN WAVE | 분신의 검기가 원본과 같은 위력이고 한 줄 더 나감 |
| 화염+냉기 | THERMAL SHOCK | 화상과 냉기가 함께 걸린 적이 증기 폭발 |
| 화염+연쇄 | OVERLOAD | 튕기는 번개가 화상을 옮기고, 불타는 적에게 화상 중첩만큼 추가 피해 |
| 화염+증식 | WILDFIRE | 불길이 스스로 주변 적에게 번져 나감 |
| 화염+복제 | DOUBLE BURN | 화상이 두 번씩 쌓이고 최대 중첩 +2 |
| 냉기+연쇄 | SUPERCONDUCT | 식은 적에서 튀는 번개 +2, 언 적을 맞힌 번개가 파쇄 |
| 냉기+증식 | ICE SHARDS | 파쇄될 때 얼음 파편이 주변 적을 쫓아감 |
| 냉기+복제 | DOUBLE CHILL | 냉기가 두 번씩 쌓임 (2번 맞히면 빙결) |
| 연쇄+증식 | SPARK SHARDS | 파편이 맞힌 적에서 번개가 한 번 더 튐 |
| 연쇄+복제 | AFTERSHOCK | 번개가 0.25초 뒤 같은 길로 한 번 더 떨어짐 |
| 증식+복제 | MIRROR SHARDS | 분신이 나타날 때 유도 파편을 흩뿌림 |

세 개 이상이면 해당하는 시너지가 모두 겹칩니다. 인챈트 카드에는 고르면 새로 켜지는 시너지가 표시되고, 화면 왼쪽 아래에 켜진 시너지 이름이 나옵니다.

웨이브를 클리어하면 카드 3장 중 하나를 골라(클릭 또는 1·2·3) 강화합니다. F1 패널의 Enchants 줄에서 레벨을 바로 바꿔 시험할 수도 있습니다.

## 부위 손상

맞으면 적 종류에 따라 다른 부위에 상처가 쌓입니다. 돌진병은 주로 팔, 유령의 탄은 머리와 몸통, 브루트는 다리를 노립니다. 팔과 다리는 베임, 골절, 절단 순으로 나빠지고, 머리와 몸통은 2단계까지 갑니다.

| 부위 | 패널티 |
|---|---|
| 검 든 팔 | 공격 속도와 피해 감소. 잘리면 검을 반대 손으로 쥐고, 두 팔이 다 잘리면 입에 뭅니다. |
| 반대 팔 | 차지가 느려지고 게이지 획득이 줄어듭니다. 잘리면 회전베기를 못 씁니다. |
| 다리 | 이동이 느려지고 절뚝입니다. 잘리면 이동 속도가 절반이 되고 바닥에 핏자국이 남습니다. |
| 머리 | 화면 가장자리가 어두워지고 조준 보정이 약해집니다. 뇌진탕이면 화면이 이중으로 보입니다. |
| 몸통 | 출혈로 체력이 계속 깎입니다 (1 아래로는 안 내려감). |

절단되는 순간에는 슬로모션, 임팩트 프레임, 잘린 팔다리가 날아가 바닥에 남는 연출이 나옵니다. 왼쪽 위 인체 아이콘과 패널티 목록으로 상태를 보여 줍니다. 층을 깰 때마다 가장 심한 상처 하나가 한 단계 낫고, 잘린 부위는 돌아오지 않습니다. F1 패널의 Wounds 줄에서 부위별로 바로 다치게 할 수 있습니다.

## 증강

5층을 깰 때마다 같은 등급(실버, 골드, 프리즘) 증강 카드 3장 중 하나를 고릅니다. 클릭이나 1·2·3으로 고르고, Z·X·C로 카드마다 한 번씩 다시 뽑을 수 있습니다. 고르는 동안은 시간이 멈추고, 고른 뒤에는 인챈트 카드가 이어서 나옵니다. 증강은 20종이며 쇠 의수(잘린 부위 복구), 혈술(출혈이 체력 회복), 불굴(절단 방지)처럼 부위 손상과 맞물리는 것도 있습니다. F1 패널의 Augments 줄에서 바로 골라 볼 수 있습니다.

## 런 구조

- **5층 보스 "잿불 감시자"**: 5·10·15층은 보스 하나만 나옵니다. 체력 900(5층 이후 층마다 강해짐), 항상 슈퍼아머, 포이즈 10. 내려찍기와 돌진으로 시작해 66%에서 2페이즈(사방 탄막), 33%에서 3페이즈(졸개 소환, 빨라진 공격)로 넘어갑니다. 보스에게 맞은 부위는 무조건 골절됩니다. 화면 위에 전용 체력바가 뜹니다.
- **새 적**: 방패병(정면 공격을 막고, 강타·찌르기·버스트에는 방패가 깨짐), 자폭병(달려와 폭발, 먼저 죽이면 주변 적까지 휘말림), 치유사(거리를 벌리고 다친 아군을 회복).
- **갈림길**: 층을 깨고 보상을 고르면 다음 층 문 2개가 나옵니다. 전투, 엘리트(적 하나가 금빛으로 강화, 클리어 시 파편 +15), 저주(적 체력 +50%·피해 +30%, 인챈트 카드 2번), 상점(파편으로 구매), 성소(완전 회복, 상처 치료, 의수 중 하나). 5층 단위 직전에는 보스 문만 나옵니다.
- **파편**: 적을 잡으면 쌓입니다(엘리트는 3배, 보스 30). 왼쪽 HUD에 표시됩니다.
- **증강 세트**: 같은 계열 증강 3개를 모으면 세트 효과가 켜집니다. 혈(처치 시 피의 폭발), 철(받는 피해 -25%), 질풍(대시로 적을 통과하면 베기), 잿불(버스트 후 대시 초기화와 치명 준비), 운명(치명타 +20%). 증강 카드에 계열과 진행도가 표시됩니다.
- **절단 전용 기술**: 팔이 하나라도 잘리면 대시 공격이 어깨 돌진(강타, 방패 파괴)으로 바뀌고, 다리가 잘리면 대시 끝에 한발 내려찍기가 나갑니다.
- **결과 화면과 영구 해금**: 죽으면 도달 층, 처치 수, 최고 콤보, 보스 처치, 잃은 팔다리를 보여 주고 잿불을 줍니다. 잿불 15/40/80/150에서 시작 파편 25, 실버 증강, 평타 인챈트, 골드 증강이 영구 해금됩니다(PlayerPrefs 저장). F1 패널의 Run 줄에서 보스 층 바로 가기, 문 열기, 파편 추가, 해금 초기화를 할 수 있습니다.

## 파일 구성

- `AshGame.cs`: 부트스트랩, 게임 루프, 렌더링, HUD, 실험 패널
- `AshPlayerSheet.cs`: 플레이어 스프라이트 시트(17모션, 90프레임)를 코드 안에 담아 두고, 상태에 맞는 프레임을 고름
- `AshEnchant.cs`, `AshGameEnchant.cs`: 인챈트 로직과 그리기·HUD·보상 카드
- `AshInjury.cs`, `AshGameInjury.cs`: 부위 손상과 증강 로직, 그리기·HUD·카드·패널
- `AshRun.cs`, `AshGameRun.cs`: 보스·새 적 행동, 갈림길·상점·성소, 증강 세트, 절단 기술, 결과·영구 해금 로직과 그리기
- `AshActors.cs`: 플레이어(콤보, 대시, 차지, 버스트, 머플러)와 적 7종(돌진병, 위습, 브루트, 방패병, 자폭병, 치유사, 보스)
- `AshWorld.cs`: 히트 판정과 모든 연출 함수(히트스톱, 흔들림, 슬로모, 임팩트 프레임, 파티클, 흔적), 웨이브
- `AshTuning.cs`: 모든 수치와 토글
- `AshArt.cs`, `AshCore.cs`: 코드로 그리는 도트, 바닥, 그림자, 글로우, 픽셀 폰트
- `AshAudio.cs`: 코드로 합성하는 효과음과 슬로모 로우패스
- `AshInput.cs`: 입력 (두 입력 시스템 모두)
- `AshRender.cs`: 픽셀 오버레이와 스프라이트 풀
- `Resources/*.shader`: 조명이 필요 없는 스프라이트 셰이더, 가산 글로우, 색수차 출력
