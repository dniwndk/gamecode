# 황동의 생애

마법공학 도시 에르덴(공력 184년)에서 한 시민의 열세 살부터 마지막 날까지를 사는 텍스트 생애 시뮬레이션. 설계는 [design/plan.md](design/plan.md).

## 실행

빌드 도구가 없는 정적 웹 게임이다. 저장소 루트에서 정적 서버를 띄우고 브라우저로 연다.

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
# 특정 시드로 시작: http://localhost:8000/index.html?seed=MY-SEED
```

## 조작

| 키 | 동작 |
|---|---|
| Space | 자동 진행 멈춤/재개 |
| Enter | 한 계절 넘기기 · 기본 버튼 |
| F | 진행 속도 1·2·4·8배 |
| 1–4 | 선택지 고르기 |
| C / T / P / M / L / K / O | 나 · 특성 · 인물 · 도시 · 장부 · 기록 보관소 · 설정 |
| Esc | 창 닫기 · 일시 정지 |

## 특성과 인연

- **긍정 특성**(청록 보석)과 **부정 특성**(달군 구리)은 판정·수입·생계비·스트레스·관계 변화에 실제 수치로 붙는다. 부정 특성 대부분은 극복하는 길이 있다.
- **열쇠 특성**(금빛 열쇠)은 수치 효과 없이 특정 사건의 선택지, 주 활동, 갈림길 루트를 연다.
- 출생 때 자질·배경에서 1~3개, 유년기 회상에서 열쇠 하나, 이후 사건 선택과 생활 습관으로 더 얻거나 잃는다.
- 인물과의 관계는 **적대 · 냉담 · 안면 · 친분 · 믿는 사이 · 평생의 인연** 여섯 단계다. 단계마다 혜택(이율, 수입, 겨울 보호, 판정)이 켜지고, 「믿는 사이」에서 열쇠를 선물받기도 한다. 일부 갈림길의 결정적 선택지는 그 단계가 되어야 열린다.
- 보유 특성은 계기판 이름 아래 토큰 줄에 늘 보이고, 클릭하거나 T 키로 특성 서랍을 연다. 연초 계획·사건·결산 창이 떠 있어도 서랍 단축키는 그대로 통한다. 사건 선택지는 열쇠·인연으로 열린 길에 띠를 두르고, 잠긴 길에는 필요한 열쇠와 단계를 적는다. 연말 결산의 「특성과 인연」 칸이 특성이 그해 실제로 움직인 숫자를 보여 준다.
- 설계 표: [design/traits.md](design/traits.md)

## 검증

```bash
node tests/sim.test.mjs --quick   # headless 기준 (특성·인연 포함, 1천 생애)
node tests/sim.test.mjs           # 전체 (1만 생애 · 10만 출생, 약 2분)
node tests/e2e.spec.mjs           # 브라우저 기준 (Playwright Chromium 필요)
node tests/audit.mjs [--quick]    # 최종 감사: 무작위 플레이 2천 회 · 상태 불변식 · 문장(조사) 검사 · 도달 가능성
node tests/audit-browser.mjs      # 최종 감사: 성능 예산 · 서랍 7종×두 테마×360px · 터치 흐름 (스크린숏 tests/out/audit/)
node tests/shots.mjs [desk|m]     # 디자인 검토용: 주요 화면 12곳을 데스크톱·모바일로 찍는다 (tests/out/shots/, 판정 없음)
```

검수 기록은 [progress.txt](progress.txt)에 쌓는다.

## 구조

- `js/core/` 규칙·시뮬레이션. DOM을 쓰지 않아 Node에서 그대로 돈다. 난수 상태는 저장 데이터 안에 있어 같은 시드와 같은 선택은 같은 삶을 만든다.
- `js/data/` 세계·인물·사건·문장 데이터.
- `js/ui/` 스팀펑크 UI. 화면(`screens/`), SVG 스프라이트, 합성 효과음, 입자, 저장소.
- `css/` 토큰 · 틀과 부품 · 화면 배치 · 모션(동작 줄이기 대응).
- `fonts/RIDIBatang.woff2` 본문 글꼴 리디바탕.
