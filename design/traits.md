# 특성과 인연 설계표

이 문서는 `js/data/traits.js`, `js/data/bonds.js`, `js/data/events/routes.js`에서 생성한 요약이다. 수치는 데이터 파일이 원본이다.

## 세 갈래

- **긍정**: 실제 수치 효과를 주는 성향
- **부정**: 삶을 무겁게 하는 성향. 극복할 길이 있는 것도 있다
- **열쇠**: 수치 효과 없이 특정 루트와 선택지를 여는 기억과 연줄

## 인연 단계

| 단계 | 조건 |
|---|---|
| 적대 | 이름을 들으면 표정이 굳는다. 도움을 청할 수 없다. |
| 냉담 | 인사는 받지만 그 이상은 없다. |
| 안면 | 얼굴과 이름을 아는 사이. |
| 친분 | 부탁 하나쯤은 들어주는 사이. (신뢰 20 또는 호감 20) |
| 믿는 사이 | 등을 맡기는 사이. 결정적인 순간에 길을 열어 준다. (신뢰 50 · 호감 20) |
| 평생의 인연 | 서로의 장례식에서 말할 사람. (신뢰 75 · 호감 50) |
