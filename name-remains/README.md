# 이름이 남는 동안 (우리가 살아남는 동안)

괴담과 격리 구역이 출근길에 섞여 있는 도시에서, 한 사람의 생애를 처음부터 끝까지 자동으로 살아 내는 텍스트 인생 시뮬레이션.
기획 원문은 [docs/claude_code_v2_0.md](docs/claude_code_v2_0.md)(명세서 v3.0)이고, 이 폴더는 그 명세를 실제로 돌아가는 웹 게임으로 옮긴 것이다.

- 플레이: https://dniwndk.github.io/gamecode/name-remains/ (main에 합쳐지면 자동 배포)
- 데스크톱 브라우저와 휴대폰에서 같은 주소로 연다. 진행 기록은 그 기기의 브라우저(IndexedDB)에만 남는다.

## 어떻게 노는가

1. 이름을 넣고(비우면 무작위) **태어나기**. 16가지 출생 중 하나가 시드로 정해진다. 빚, 낙인, 저주받은 유품도 함께 태어난다.
2. 0세부터 **한 번에 한 해씩** 흐른다. 어린 시절에는 해마다 한 줄씩 기록이 남고, 한 해 걸러 한 번쯤 작은 갈림길(어린 시절 선택 22종)이 찾아와 고르는 대로 적성이 기운다.
3. 사회에 나오면 일하고 쉬고 수련하는 일은 왼쪽의 **생활 방침**(생계/회복/수련/돌봄/조사)과 **위기 원칙**(퇴로/동행자/임무)에 따라 굴러가고, 해마다 끝에 "한 해" 정리 한 줄이 남는다. 1~2년에 한 번은 일상의 갈림길(30종)이 찾아온다.
4. 괴담 사건이 터지면 시간이 멈추고 **선택 카드**가 뜬다. 알고 있는 단서가 위에 요약되고, 단서나 능력으로 열리는 선택에는 `규칙 파훼 시도`·`보유 능력` 배지가, 함정에는 `함정 의심` 배지가 붙는다. 확정으로 통하는 길은 없다. 파훼도 판정을 거치고, 어긋나면 반동으로 다친 뒤 같은 자리에서 남은 길을 골라야 한다. 본 선택 아래에는 **작은 행동**(살피기·응급처치·숨 고르기·부적 붙이기 등 14종 중 세 가지)이 열린다. 작은 행동은 해도 결정이 그대로 남고, 성공하면 이번 사건의 판정에 보정이 쌓인다.
5. 판정에 실패하면 **영구 상해**(시력 저하, 손가락 신경 손상, 성대 손상, 다리 부상 후유증, 그림자 상실 등 14종)가 남을 수 있다. 상해는 그 생애가 끝날 때까지 적성·최대 건강·수명 한계를 깎고, **다친 부위를 쓰는 선택지**를 바꿔 놓는다. 눈·손·귀·기억 등을 쓰는 선택은 성공률이 떨어지거나(판정 없는 선택은 건강·피로 부담). 카드에는 다친 곳을 써야 한다는 것만 보이고, 얼마나 불리했는지는 결과에 찍힌다, 성대 손상이면 소리치기, 다리 부상이면 달리기, 허리 손상이면 부축, 폐 손상이면 숨 참기를 아예 고를 수 없다. 선택지가 쓰는 부위는 `src/content/bodyUse.ts`에 적혀 있다. 무언가를 빼앗아 가는 것이 본성인 고등급 괴담 네 가지(종이에 없는 바다, 신이 돌아본 자리, 기록말소국 활자 범람, 최후의 기슭)는 최선의 선택으로 살아 나와도 그 괴담에 맞는 상해나 대가를 하나 가져간다.
6. 어른이 되면 일상 사이로 **몸을 노리는 위협**(계단참의 손, 시장의 칼잡이, 등을 미는 손, 차오르는 지하차도 등 10종)이 끼어든다. 어느 길을 골라도 무언가를 잃거나 다칠 수 있고, 지면 상해가 남기 쉽다.
7. **빚과 피로**: 밀린 돈이 있으면 매번 몸이 깎이고 판정이 불리해진다. 500 넘게 밀리면 독촉과 폭행이 찾아오고 쉴 틈도 없어지며, 그대로 약 2년을 버티면 빚에 짓눌려 죽는다(처음부터 안고 태어난 빚은 그 위로 더 진 만큼만 센다. 65세부터는 죽음까지 가지 않는다). 피로가 100에 닿으면 크게 앓고, 90 이상에 반년쯤 머물면 몸이 멈춘다.
8. 선택지에는 무엇이 오르고 내리는지 적혀 있지 않다. 고른 **직후 결과 줄에** 실제 증감이 찍히고, 어떤 선택이 무엇을 움직이는지는 여러 회차를 거치며 경험으로 익힌다. 선택으로 얻은 적성·숙련은 운에 맡기지 않고 쌓이며, 1에 못 미치면 `관찰 경험 +12%`처럼 쌓인 몫이 찍힌다. 괴담 사건의 본 선택은 결과와 별개로 판정에 쓰인 숙련을 조금씩 올린다.
9. 죽음, 소멸, 승천, 불멸, 영속 성역, 영원한 구속 중 하나의 **종점**에 닿으면 묘비명과 스포일러 없는 공유 문구가 나온다. 업적은 도감(66종)과 생애실에 남는다.

단축키: `Space` 일시정지 · `[` `]` 속도 · `1`~`9` 선택 · `N` 다음 선택까지 · `Esc` 포기 확인.

## 개발

```bash
cd name-remains
npm ci
npm run dev        # http://localhost:5173
npm test           # 콘텐츠 검사 + 결정성·일시정지·저장소 + 자동 생애 1000회
npm run build      # dist/ (상대 경로 빌드라 어느 하위 경로에 올려도 열린다)
npm run test:e2e   # 빌드본을 실제 Chromium으로 열어 데스크톱·휴대폰에서 한 생애씩 끝까지 플레이
```

`test:e2e`는 Playwright가 필요하다. 저장소 루트의 `npm ci`가 설치하는 것을 그대로 쓴다.

| `src/content/` | 명세의 데이터 팩: 출생 16, 생활권 5, 성장 경로 10, 형태 11, 능력 30, 활동 16, 소사건 20, 주요 사건 20 + 인물 호출·사후 장면, 업적 66, 안내문. 여기에 더해 `lifeChoices.ts`(어린 시절 한 해 기록·갈림길 22, 일상 갈림길 30)와 `sideActions.ts`(작은 행동 14) |
| `src/store/` | Zustand 상태와 IndexedDB 저장(회차·판정 사실·계정 기록을 한 트랜잭션으로) |
| `src/ui/` | React 화면: 타이틀, 인생 진행(3단 → 휴대폰은 1단 + 바텀시트), 결말, 도감, 생애실, 설정 |

### 지킨 규칙

- 같은 시드 + 같은 선택 = 같은 삶. 속도(1x~8x)와 건너뛰기는 결과를 바꾸지 않는다(시험으로 확인).
- 출생과 업적 판정은 이번 회차만 본다. 이전 회차의 기록은 확률에 섞이지 않는다.
- 얻지 못한 업적은 등급·제목·암시만 화면에 나간다. 해금 설명은 얻은 뒤에만 보인다.
- 명세에서 삭제된 "동시대 출생자 4인 비교"와 "1칸=1년 인생 지도 그리드"는 만들지 않았다.
- 판정 공식은 명세 02.2절의 `P = clamp(B + 0.04·A_rel + 0.004·M_rel + S_prep + S_ally − D_threat − C_penalty, 0.05, 0.95)`. 적성·숙련은 괴담 등급이 요구하는 수준에 대한 상대값으로 넣는다.

### 균형(자동 생애 1000회 기준)

- 생애당 선택 약 70회(어린 시절 갈림길, 일상 갈림길, 괴담 사건, 작은 행동 포함), 주요 사건 약 9회. 1배속으로 한 해 2.6초, 선택을 빼면 한 생애 약 6분.
- 아무거나 고르면 약 76%가 늙기 전에 험하게 죽고, 약 91%가 영구 상해를 하나 이상 안고 산다. 늘 가장 안전해 보이는 선택을 골라도 약 53%가 험하게 죽는다. 나머지는 늙어서 생을 마친다.
- 신화 등급 자리(각 경로의 정점)에는 신중하게 골라도 약 9%만 닿는다.
- 사후 지속은 조건을 갖춘 죽음의 약 5%에서만 일어나고, 영원한 구속·불멸·영속 성역 같은 특수 종점은 합쳐서 2~5%다.
- 적성(0~10)은 높을수록 오르기 어려워 한 생애 끝 평균이 5~7 정도다. 일상 활동보다 선택과 사건이 적성을 더 크게 움직인다.
- 수치는 `src/domain/engine.ts` 머리의 상수와 `src/domain/lifePlanner.ts`에서 조정한다.
