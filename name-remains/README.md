# 이름이 남는 동안 (우리가 살아남는 동안)

괴담과 격리 구역이 출근길에 섞여 있는 도시에서, 한 사람의 생애를 처음부터 끝까지 자동으로 살아 내는 텍스트 인생 시뮬레이션.
기획 원문은 [docs/claude_code_v2_0.md](docs/claude_code_v2_0.md)(명세서 v3.0)이고, 이 폴더는 그 명세를 실제로 돌아가는 웹 게임으로 옮긴 것이다.

- 플레이: https://dniwndk.github.io/gamecode/name-remains/ (main에 합쳐지면 자동 배포)
- 데스크톱 브라우저와 휴대폰에서 같은 주소로 연다. 진행 기록은 그 기기의 브라우저(IndexedDB)에만 남는다.

## 어떻게 노는가

1. 이름을 넣고(비우면 무작위) **태어나기**. 16가지 출생 중 하나가 시드로 정해진다. 빚, 낙인, 저주받은 유품도 함께 태어난다.
2. 유년기 세 줄이 지나가면 본격적인 삶이 14일 단위로 저절로 흐른다. 조용한 보름들은 한 줄의 일상 기록으로 묶인다.
3. 왼쪽의 **생활 방침**(생계/회복/수련/돌봄/조사)과 **위기 원칙**(퇴로/동행자/임무)만 정해 두면 일하고 쉬고 수련하는 일은 알아서 굴러간다.
4. 괴담 사건이 터지면 시간이 멈추고 **선택 카드**가 뜬다. 알고 있는 단서가 위에 요약되고, 확실히 통하는 선택에는 `규칙 파훼 확정`·`보유 능력 작동` 배지가, 함정에는 `함정 의심` 배지가 붙는다.
5. 죽음, 소멸, 승천, 불멸, 영속 성역, 영원한 구속 중 하나의 **종점**에 닿으면 묘비명과 스포일러 없는 공유 문구가 나온다. 업적은 도감(66종)과 생애실에 남는다.

단축키: `Space` 일시정지 · `[` `]` 속도 · `1`~`9` 선택 · `N` 다음 선택까지 · `Esc` 포기 확인.

## 개발

```bash
cd name-remains
npm ci
npm run dev        # http://localhost:5173
npm test           # 콘텐츠 검사 + 결정성·일시정지·저장소 + 자동 생애 1000회
npm run build      # dist/ (상대 경로 빌드라 어느 하위 경로에 올려도 열린다)
npm run test:e2e   # 빌드본을 실제 Chromium으로 열어 데스크톱·휴대폰에서 한 생애씩 끝까지 플레이
```

`test:e2e`는 Playwright가 필요하다. 저장소 루트의 `npm ci`가 설치하는 것을 그대로 쓴다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `src/domain/` | 화면과 무관한 순수 규칙. 시드 난수(Mulberry32, 출생·세계·행동 세 갈래), 조건식, 자동 진행 엔진, 판정, 사망·사후·종점, 업적 판정, 화면용 선택자 |
| `src/content/` | 명세의 데이터 팩: 출생 16, 생활권 5, 성장 경로 10, 형태 11, 능력 30, 활동 16, 소사건 20, 주요 사건 20 + 인물 호출·사후 장면, 업적 66, 안내문 |
| `src/store/` | Zustand 상태와 IndexedDB 저장(회차·판정 사실·계정 기록을 한 트랜잭션으로) |
| `src/ui/` | React 화면: 타이틀, 인생 진행(3단 → 휴대폰은 1단 + 바텀시트), 결말, 도감, 생애실, 설정 |
| `src/audio.ts` | 파일 없이 Web Audio로 합성하는 효과음 8종. 모든 소리는 `[청각 자막]`과 함께 나온다 |
| `tests/` | vitest 단위·대량 시뮬레이션, `tests/e2e/play.e2e.mjs` 브라우저 플레이 |

### 지킨 규칙

- 같은 시드 + 같은 선택 = 같은 삶. 속도(1x~8x)와 건너뛰기는 결과를 바꾸지 않는다(시험으로 확인).
- 출생과 업적 판정은 이번 회차만 본다. 이전 회차의 기록은 확률에 섞이지 않는다.
- 얻지 못한 업적은 등급·제목·암시만 화면에 나간다. 해금 설명은 얻은 뒤에만 보인다.
- 명세에서 삭제된 "동시대 출생자 4인 비교"와 "1칸=1년 인생 지도 그리드"는 만들지 않았다.
- 판정 공식은 명세 02.2절의 `P = clamp(B + 0.04·A_rel + 0.004·M_rel + S_prep + S_ally − D_threat − C_penalty, 0.05, 0.95)`. 적성·숙련은 괴담 등급이 요구하는 수준에 대한 상대값으로 넣는다.

### 균형(자동 생애 1000회 기준)

- 생애당 선택 약 15회, 주요 사건 약 9회. 1배속으로 한 생애 약 15분.
- 늘 가장 안전한 선택을 고르면 사건 속 사망이 약 10%, 아무거나 고르면 약 35%. 나머지는 늙어서 생을 마친다(평균 80세 안팎).
- 사후 지속은 조건을 갖춘 죽음의 약 5%에서만 일어나고, 영원한 구속·불멸·영속 성역 같은 특수 종점은 합쳐서 2~5%다.
- 수치는 `src/domain/engine.ts` 머리의 상수와 `src/domain/lifePlanner.ts`에서 조정한다.
